# Data and code availability

The procedural sedation recordings used for the original validation and development analyses are available as [DOSE-I version 1 from Zenodo](https://doi.org/10.5281/zenodo.18483292), subject to the accompanying dataset-use terms. This repository links to the provider and does not redistribute the recordings. The protected evaluation split did not contribute to the diagnostic readout or direct-state intervention findings.

The public snapshot includes portable analysis code, generated verification examples, and a source table for the aggregate EEG subspace effects. Frozen participant roles, checkpoints, and participant-level results are not distributed in this version. Their release depends on a separately approved sharing scope.

Code and software documentation are available under the [MIT License](../LICENSE). The source recordings retain the provider's data-use terms.
